# Page Society Template Generator

Page Society Template Generator is a desktop application for producing
professional, print-ready book cover templates. This repository currently
contains the Milestone 1 application foundation only; template generation,
calculations, previews, and exports are not yet implemented.

## Requirements

- Python 3.13 or newer
- PySide6

## Run

Create and activate a virtual environment, then install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

The initial application shell displays a toolbar, left navigation panel,
central live-preview area, right properties panel, and status bar.
